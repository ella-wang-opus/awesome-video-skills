## 收录范围

这是一个 **video-first** 的目录。主目录只收录至少支持 **Claude 或 Codex 其中一个**、并能实际帮助 Agent 制作成片的 Skill 或 Skill 套件，包括调研、剧本、分镜、素材生成、动效、剪辑、字幕、声音、渲染和质检。

视觉类 Skill 只作为辅助收录，用于改善视频的美术方向、3D 元素、源素材或需要录制的产品体验。

> 点击 Preview 查看完整演示。点击投票徽章，然后在对应 GitHub Issue 添加 👍 reaction。README 票数可能延迟 2–5 分钟刷新。

## 推荐一个 Skill

发现值得收录的开源 Skill？欢迎[提交 Issue](https://github.com/ella-wang-opus/awesome-video-skills/issues/new)，请附上：

- GitHub 仓库和作者
- 它支持的视频制作环节
- 一句话简介
- Preview 图片、GIF 或视频
- 应归入「核心视频制作」还是「视觉辅助」

项目应提供可供 Claude 或 Codex 安装的 `SKILL.md` 工作流，或清晰记录的 Agent Skill 套件。普通视频代码库和只有 Prompt 的集合不在收录范围内。
