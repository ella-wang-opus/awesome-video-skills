## What belongs here?

The index is **video-first**. The main collection contains installable agent skills and skill suites for at least one supported host — **Claude or Codex** — that materially help produce a finished video: research, scripting, storyboards, asset generation, motion design, editing, captions, audio, rendering, or QA.

Visual skills live in a smaller supporting collection when they can improve a video's art direction, 3D elements, source material, or captured product experience.

> Click a preview to see the full demo. To vote, click a vote badge and add a 👍 reaction on its GitHub Issue. README counts may take 2–5 minutes to refresh.

<sub>* `Claude / Codex*` denotes a standard portable `SKILL.md`; the repository does not document host-specific testing.</sub>

## Suggest a Skill

Found an open-source skill that belongs here? [Open an issue](https://github.com/ella-wang-opus/awesome-video-skills/issues/new) with:

- GitHub repository URL and creator
- The video-production stage it supports
- One-sentence description
- Preview image, GIF, or video URL
- Whether it belongs in **Core Video Production** or **Visual Support**

Projects should provide an installable `SKILL.md` workflow or a clearly documented agent-skill suite for Claude or Codex. General video libraries and prompt-only collections are out of scope.
